# 🛡️ THE FRAUDVERSE — Sri Vidya Deshaboina

> An interactive, game-style portfolio for a **Fraud Investigation Analyst / AML · KYC · Trust & Safety / Sanctions Screening** professional.

Instead of a traditional resume site, this is **"Payment City"** — a luxury animated experience where the visitor plays through investigation missions that reveal Sri Vidya's real skills and 5+ years of experience.

🔗 **Live site:** https://srividyadeshaboinasri-hub.github.io/video_portfolio/

---

## ✨ Experience Highlights

- **Cinematic boot intro** — `Loading Payment City… Activating AML Engine… Access Granted`
- **Interactive city map** — 7 glass towers that glow on hover and open missions
- **5 playable missions:**
  1. **Account Takeover Attack** — magnifying-glass scan, animated risk meter, actor blocked
  2. **AML Money Trail** — follow funds across glass accounts; red = suspicious laundering paths
  3. **Sanctions World Shield** — activate OFAC / EU / UN / HMT shields to stop a cross-border transaction
  4. **SAR / STR Report Room** — collect evidence to draft a regulatory filing
  5. **Career Level Map** — 5 levels unlock on scroll with 🏆 achievement pop-ups
- **Skill Power Cards** — collectible cards that flip on hover to reveal abilities
- **Start a New Investigation** — contact section with a flying golden envelope

## 🛠️ Tech Stack

## 🚀 Run Locally

```bash
npm install
npm run dev      # start dev server (http://localhost:5173)
npm run build    # production build
npm run preview  # preview the production build
```

---

## 📦 Deployment

Hosted on **GitHub Pages** via GitHub Actions (builds on every push to `main`).
Vite `base` is set to `/video_portfolio/` for project-site hosting.
